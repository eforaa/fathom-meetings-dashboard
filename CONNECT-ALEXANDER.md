# Подключить Александра к базе встреч (задача №1)

Всё уже построено: коннектор, доступ по токенам, скиллы `manage-meetings` и
`analyze-meeting`. Осталось выкатить и подключить. Технический референс —
[MCP-SETUP.md](MCP-SETUP.md); здесь — только «что сделать сейчас».

> Токен Александра привязан к **`ceo@aivocado.ai`** — под этим email в базе
> лежат его 404 встречи. Значение токена — в `.env.local` (не коммить его).
> Ниже он обозначен как `<ТОКЕН>`.

## Часть A. Для Sofiia — выкатить (3 шага)

### 1. Запушить ветку `dev`
6 коммитов не запушены. Пуш отбивается, потому что Windows подставляет не тот
GitHub-аккаунт (репозиторий под `eforaa`). Починить один раз:

```bash
gh auth login
```

Выбрать GitHub.com → HTTPS → войти под аккаунтом, у которого есть доступ к
`eforaa/fathom-meetings-dashboard`. Если `gh` нет — почистить старый логin в
**Windows → «Диспетчер учётных данных» → Учётные данные Windows → github.com**,
удалить запись и запушить заново (Windows спросит логин заново):

```bash
git push origin dev
```

> Перед пушем реши, что коммитить. Правки автозаголовков (Agent SDK в
> `scripts/generate-titles.mjs`) — задача №3, их пока лучше **не** коммитить.

### 2. Прописать токены в Vercel
Vercel → Project → **Settings → Environment Variables** → `MCP_TOKENS`
(значение как в `.env.local`, обе пары через запятую, без пробелов):

```
<токен_Даниила>:d.soloviov@aivocado.ai,<ТОКЕН>:ceo@aivocado.ai
```

Сохранить и **передеплоить** (Deployments → Redeploy), иначе переменная не
подхватится.

### 3. Проверить
После деплоя коннектор живёт по адресу:

```
https://fathom-meetings-dashboard.vercel.app/api/mcp/<ТОКЕН>
```

## Часть B. Для Александра — подключить свой Claude

**1. Добавить коннектор.**

В Claude Code:
```bash
claude mcp add fathom-meetings --transport http https://fathom-meetings-dashboard.vercel.app/api/mcp/<ТОКЕН>
```

Или в claude.ai → **Settings → Connectors → Add custom connector** → вставить
тот же адрес.

**2. Что Claude теперь умеет** (видит только твои встречи):
- находить встречи — по типу, датам, участнику, поиску в названии;
- открывать карточку: саммари, темы, задачи, участники, транскрипт;
- править: название, саммари, важность (звёзды), типы;
- заводить свои колонки и проставлять теги — и по одной, и пачкой по паттерну.

**3. Примеры запросов:**
- «Покажи мои встречи с клиентами за последний месяц таблицей.»
- «Найди все встречи про WorkOS и проставь им тип и тег „методология“.»
- «Заведи колонку „проект“ (выпадающий список) и заполни по темам встреч.»

Скиллы `manage-meetings` и `analyze-meeting` учат Claude пользоваться базой
правильно — они лежат в репозитории в папке `skills/`.
