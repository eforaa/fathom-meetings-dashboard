# Гайд: автозаголовки встреч + редактирование названий

Две вещи: как менять названия зумов и как включить короткие AI-заголовки.

---

## Часть 1. Менять названия зумов — уже готово

Александр просил, чтобы названия встреч можно было менять. Сделано, подключать
ничего не нужно:

- **В списке** — наведи на строку, справа от названия карандашик ✎, нажми →
  поле ввода → Enter сохраняет, Esc отменяет.
- **На странице встречи** — тот же карандашик у заголовка.
- **Через Claude** — инструмент `set_meeting_title` в коннекторе: «переименуй
  эту встречу в …».

Правленое название главнее автоматического. Пустое поле — откат к авто.
Нужна колонка `custom_title` (миграция ниже, если не накатана).

## Часть 2. Короткие заголовки — сейчас без ИИ

### Как сейчас

Заголовки берутся из строки **«Цель встречи»** конспекта Fathom — это простая
обработка текста, который уже лежит в базе. Никакого стороннего ИИ. Название
выходит осмысленным, но иногда длинноватым (целое предложение цели).

### Про генерацию через ИИ (на будущее, пока не делаем)

Короткие заголовки в 3–6 слов даёт только языковая модель. Варианты и их статус:

- **Claude Agent SDK через подписку** — ❌ нельзя. В официальных доках Agent SDK
  прямо запрещено использовать вход по подписке в продуктах; только API-ключ.
- **Свой ключ Anthropic** — разрешено, но платно; ждёт решения заказчика.
- **Сторонние модели (OpenRouter и т.п.)** — пока не используем по решению.

Место под будущий ИИ-шаг помечено в скрипте (функция `generateTitle`).

### Шаг 1. Колонка в базе (один раз)

Если ещё не накатана — [SQL Editor](https://supabase.com/dashboard/project/xieywsveunlrqbqzzkhf/sql/new):

```sql
alter table meetings add column if not exists custom_title text;
```

### Шаг 2. Запуск

В PowerShell, в папке проекта:

```bash
node scripts/generate-titles.mjs 20
```

Число — сколько встреч за раз (по умолчанию 20). Скрипт печатает заголовки и
пишет их в `custom_title`. Трогает только встречи с **пустым** `custom_title` —
ручные правки и уже готовые заголовки не затирает.

### Перегенерировать заголовки

Скрипт не трогает заполненные `custom_title`. Если надо переделать — сначала
очисти нужные (в Supabase или скриптом), потом запусти генерацию снова.

## Если что-то не так

| Сообщение | Что значит | Что делать |
|---|---|---|
| `SUPABASE_URL is not set` | нет `.env.local` рядом | запускать из папки проекта |
| `column ... custom_title does not exist` | нет колонки | шаг 1 |
| `nothing to title — all caught up` | нечего делать | всё с заголовками, это норма |

## Коротко

- **Менять названия** — готово: карандашик в интерфейсе + `set_meeting_title` у Claude.
- **Заголовки сейчас** — из «Цели встречи» конспекта, без ИИ:
  `node scripts/generate-titles.mjs`.
- **Короткие ИИ-заголовки** — на паузе: Agent SDK по подписке нельзя (условия
  Anthropic), сторонние модели по решению не используем, свой ключ Anthropic —
  ждёт решения.
