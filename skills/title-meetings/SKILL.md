# Короткие названия безымянным встречам

Незапланированные встречи приходят из Fathom с бессмысленным названием
**«Impromptu Zoom Meeting»** — по такой базе невозможно искать. Твоя задача —
дать им короткое осмысленное название. Всё идёт через коннектор
**fathom-meetings**; ты видишь и меняешь только встречи владельца токена.

Только табличная правка названия — сам разбор транскрипта (темы, тип, задачи)
это отдельный скилл `analyze-meeting`.

## Принцип названия

Заголовок = **суть темы (3–5 слов, без глаголов)** + **фамилии 1–3 ключевых
участников в скобках**. На языке саммари.

**Суть темы бери из ЦЕЛИ встречи**, а не из `key_topics` и не выдумывай из
транскрипта. Цель — это первая строка саммари Fathom (`fathom_summary`), под
заголовком «Цель встречи»/«Purpose». Опирайся на неё, убери глаголы, оставь суть.
Цель уже есть в саммари — **не спрашивай её у человека**.

- ✅ «Плагин Fathom — синхронизация данных (Погорелый, Олийник, Веденеева)»
- ❌ «PM плагин — миграция БД» (это инструменты из транскрипта, а не цель)
- ❌ «Согласовать разработку плагина Fathom» (это цель дословно, с глаголом — убери глагол)
- ❌ «Impromptu Zoom Meeting» (бессмысленно)

Правила по именам:
- В скобках именно **фамилии**, не имена.
- Держи **один алфавит** — не мешай кириллицу и латиницу в одном заголовке.
  Если имена участников на латинице, а саммари на русском — аккуратно
  транслитерируй и пиши фамилии единообразно (одного человека всегда одинаково).
- Максимум 3 фамилии, бери ключевых участников встречи.

## Как делать

1. **Найти безымянные.** `list_meetings` с `search: "Impromptu"` (или пройди
   список и отбери те, где `title` = «Impromptu Zoom Meeting», а `custom_title`
   пустой). Уже названные встречи не трогай.
2. **Прочитать встречу.** Для каждой — `get_meeting`: бери `fathom_summary`
   (готовое саммари Fathom) и список `participants` (их имена).
3. **Собрать заголовок** по принципу выше — суть из ЦЕЛИ встречи (первая строка
   `fathom_summary`, под «Цель встречи»/«Purpose»), плюс фамилии участников.
4. **Записать.** `set_meeting_title` (`id`, `title`).

## Правила

- **Перед массовым прогоном** сначала назови **3–5 встреч**, покажи владельцу
  «старое → новое» и дождись подтверждения. Понравилось — продолжай пачками.
- **Только безымянные** — встречу, у которой уже есть нормальное название
  (`custom_title` или осмысленный `title`), не переименовывай.
- **id бери только из инструментов**, не придумывай.
- Если фамилия участника непонятна или её нет (только имя) — используй имя, а при
  сомнении спроси владельца, как правильно писать.
- После записи коротко подтверди, сколько встреч и как назвал, без пересказа
  каждого саммари.
